# Lab 3: Vector Data Creation, On-Screen Digitization & Snapping Rules

**Course Code:** CE452 | **Credits:** 2 | **Week:** 3  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO2 (L3 - Apply)  
**Primary Tools:** QGIS Vector Editing, Snapping Toolbar, OGC GeoPackage (.gpkg)

---

## 🎯 Aim & Objectives
1. Understand vector geometric primitives: **Points**, **Linestrings (Polylines)**, and **Polygons**.
2. Create an **OGC GeoPackage (`campus_infrastructure.gpkg`)** container with schema definitions and attribute fields.
3. Configure **Snapping Options** (Vertex, Segment, Topological Editing, Avoid Overlap).
4. Perform on-screen digitization of civil infrastructure features (roads, buildings, trees, drainage network) over a georeferenced satellite basemap.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: GeoPackage Container Creation
:::steps
1. Navigate to **Layer $\rightarrow$ Create Layer $\rightarrow$ New GeoPackage Layer...** (`Ctrl + Shift + N`).
2. Set Database location: `D:\CE452_GIS_Lab\Vectors\campus_infrastructure.gpkg`.
3. Create three distinct feature classes inside this GeoPackage:
   - **Layer 1: Buildings** (Geometry: `Polygon`, CRS: `EPSG:4326 - WGS 84`)
     - Attribute Fields: `name` (Text), `floors` (Integer), `height_m` (Decimal), `usage` (Text).
   - **Layer 2: Road_Network** (Geometry: `LineString`, CRS: `EPSG:4326 - WGS 84`)
     - Attribute Fields: `road_name` (Text), `width_m` (Decimal), `surface_type` (Text: Asphalt/Concrete/Paved).
   - **Layer 3: Utilities** (Geometry: `Point`, CRS: `EPSG:4326 - WGS 84`)
     - Attribute Fields: `asset_type` (Text: Borewell/LampPost/Manhole), `status` (Text: Operational/Defective).
:::

### Phase 2: Configuring Snapping & Topological Rules
:::steps
1. Enable the **Snapping Toolbar** (**Project $\rightarrow$ Snapping Options...** or click the magnet icon).
2. Set snapping mode to:
   - Snapping Type: **Vertex and Segment**
   - Tolerance: **10 pixels** or **2 meters**
   - Enable **Topological Editing** (ensures shared boundaries move together without gaps).
   - Enable **Avoid Overlap on Active Layer** (prevents overlapping polygons during parcel digitization).
:::

### Phase 3: Digitization & Vertex Editing
:::steps
1. Select the `Buildings` layer in the Layers panel and click the yellow pencil icon (**Toggle Editing** / `Ctrl + E`).
2. Click **Add Polygon Feature** (`Ctrl + .`).
3. Digitize building footprints by clicking along the corners. Right-click to finish each feature and enter the attribute values in the pop-up form.
4. Select `Road_Network` $\rightarrow$ Toggle Editing $\rightarrow$ Click **Add Line Feature**. Trace centerlines of access roads, snapping accurately at junctions.
5. Select `Utilities` $\rightarrow$ Add point features for borewells, rain gauges, and street lights.
6. Click **Save Layer Edits** and turn off the pencil icon.
:::

## 📋 Deliverables
1. Compact GeoPackage file `campus_infrastructure.gpkg` containing all three digitized vector layers.
2. Minimum digitized count: 10 buildings, 5 road segments with connected nodes, 10 utility points.
