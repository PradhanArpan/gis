# Lab 13: Spatial Interpolation: IDW, Spline & Ordinary Kriging

**Course Code:** CE452 | **Credits:** 2 | **Week:** 13  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO3 (L4 - Analyze)  
**Primary Tools:** QGIS Interpolation, GDAL Grid, SAGA Geoscience

---

## 🎯 Aim & Objectives
1. Understand deterministic vs geostatistical spatial interpolation for environmental observations.
2. Ingest point CSV monitoring data (e.g. 25 district rain gauges or groundwater depth observation wells).
3. Generate continuous spatial raster surfaces using:
   - **Inverse Distance Weighting (IDW)** (Distance-decay power parameter $p = 2$)
   - **Thin Plate Spline (RBF)** (Smooth continuous curvature surface)
   - **Ordinary Kriging** (Spatial autocorrelation semivariogram modeling)
4. Evaluate cross-validation prediction errors: **Root Mean Square Error (RMSE)**.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Ingesting Point Observation CSV
:::steps
1. Navigate to **Layer $\rightarrow$ Add Layer $\rightarrow$ Add Delimited Text Layer...**.
2. Select `district_rainfall_stations.csv`.
3. X field: `Longitude`, Y field: `Latitude`, Geometry CRS: `EPSG:4326`.
4. Reproject points into metric UTM coordinates (`EPSG:32643`).
:::

### Phase 2: Inverse Distance Weighting (IDW)
:::steps
1. Open **Processing Toolbox $\rightarrow$ Interpolation $\rightarrow$ IDW Interpolation**.
2. Vector layer: `district_rainfall_stations_utm`
3. Interpolation attribute: `Annual_Rainfall_mm`
4. Click `+` to add the vector layer to the interpolation list.
5. Distance coefficient $P$: `2.0` (standard inverse square distance weighting).
6. Extent: Set to District Boundary layer extent.
7. Output raster pixel size: `50 meters`.
8. Output: `Rainfall_IDW_surface.tif`. Click **Run**.
:::

### Phase 3: Ordinary Kriging with SAGA
:::steps
1. In Processing Toolbox, search for **Ordinary Kriging** (SAGA).
2. Set Target Grid cell size to `50 m`.
3. Variogram model: `Spherical` or `Exponential`.
4. Run algorithm to produce both the **Predicted Value Surface** and the **Kriging Variance (Uncertainty) Grid**.
5. Mask/Clip the continuous raster by the official district boundary polygon.
:::

2. Comparative analysis of IDW vs Kriging surfaces and root mean square error (RMSE).
