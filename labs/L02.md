# Lab 2: QGIS Environment Setup & Web Basemap Integration

**Course Code:** CE452 | **Credits:** 2 | **Week:** 2  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO1, CO2 (L2, L3)  
**Primary Tools:** QGIS 3.x/4.x, XYZ Tiles, QuickMapServices Plugin

---

## 🎯 Aim & Objectives
1. Configure the QGIS desktop user interface, panels, and project properties for engineering projects.
2. Add, manage, and configure standard web tile services (XYZ Tiles) including OpenStreetMap, Google Satellite, and CartoDB.
3. Install and utilize the **QuickMapServices** plugin to rapidly access global geospatial basemaps.
4. Set default project Coordinate Reference Systems (CRS) and configure measurement units (Meters / Kilometers).

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: User Interface Customization
:::steps
1. Launch QGIS. Right-click on any empty area of the top toolbar to inspect active panels and toolbars.
2. Ensure the following panels are enabled:
   - **Layers Panel** (displays loaded data layers and render hierarchy)
   - **Browser Panel** (file system explorer for GeoPackages, Shapefiles, and Web Services)
   - **Processing Toolbox** (searchable library of GIS analysis algorithms)
3. Under **Settings $\rightarrow$ Options $\rightarrow$ Map Tools**, set the default distance measurement units to **Meters** and area units to **Square Meters / Hectares**.
:::

### Phase 2: Adding XYZ Web Tile Connections
:::steps
1. In the **Browser Panel**, locate and right-click on **XYZ Tiles** $\rightarrow$ select **New Connection...**.
2. Add the following high-resolution satellite and cartographic basemap URLs:
   - **Google Hybrid Satellite**:
     - *Name:* `Google Satellite Hybrid`
     - *URL:* `https://mt1.google.com/vt/lyrs=y&x={x}&y={y}&z={z}`
   - **ESRI World Imagery**:
     - *Name:* `ESRI Satellite`
     - *URL:* `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`
   - **CartoDB Positron (Clean Background for Mapping)**:
     - *Name:* `CartoDB Positron`
     - *URL:* `https://a.basemaps.cartocdn.com/light_all/{z}/{x}/{y}.png`
3. Double-click any added tile service to load it into the canvas.
:::

### Phase 3: Installing & Using QuickMapServices Plugin
:::steps
1. Go to **Plugins $\rightarrow$ Manage and Install Plugins...**.
2. In the Search bar, type `QuickMapServices`.
3. Click **Install Plugin**.
4. Once installed, navigate to the top menu: **Web $\rightarrow$ QuickMapServices $\rightarrow$ Settings**.
5. Switch to the **More services** tab and click **Get contributed pack** (unlocks 50+ satellite, topographic, and weather basemaps).
6. Add **OSM Standard** and **Google Satellite** to compare resolution differences over your institution campus.
:::
