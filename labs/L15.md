# Lab 15: Web GIS, OpenStreetMap Extraction & Capstone GeoPackage Packaging

**Course Code:** CE452 | **Credits:** 2 | **Week:** 15  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO2, CO3, CO5 (L4, L5)  
**Primary Tools:** QuickOSM Plugin, Overpass Turbo API, OGC GeoPackage Packaging

---

## 🎯 Aim & Objectives
1. Connect QGIS to live Web GIS services: WMS, WFS, and OpenStreetMap Overpass API.
2. Install the **QuickOSM** plugin and write queries to download live vector layers (buildings, highways, waterways, emergency services).
3. Compile all semester lab deliverables into a unified, portable **OGC GeoPackage (`Capstone_GIS_Repository.gpkg`)** container.
4. Export web-ready GeoJSON formats for web mapping libraries (Leaflet / MapLibre).

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Querying OpenStreetMap via QuickOSM
:::steps
1. Install the **QuickOSM** plugin from **Plugins $\rightarrow$ Manage and Install Plugins...**.
2. Open QuickOSM (`Vector → QuickOSM → QuickOSM`).
3. In the Quick query tab:
   - Key: `amenity`, Value: `hospital` (or `school`)
   - In: Enter your city name (e.g., `Bengaluru` or `Kolkata`) or set extent to Canvas Extent.
   - Click **Run query**.
4. In seconds, points and polygons matching the query are downloaded directly into your QGIS session!
5. Repeat for:
   - Key: `highway` (extracts full transportation road network)
   - Key: `waterway` (extracts streams, canals, and drainage lines)
:::

### Phase 2: Packaging into an OGC GeoPackage
:::steps
1. In the QGIS Browser panel, right-click on **GeoPackage** $\rightarrow$ **Create Database...**.
2. Name it `Capstone_GIS_Repository.gpkg`.
3. In the Layers panel, right-click each layer from Labs 1 through 14 (e.g. `Buildings`, `Roads`, `Contours`, `Watershed_Boundary`, `LULC_Polygon`) $\rightarrow$ **Export $\rightarrow$ Save Features As...**.
4. Format: **GeoPackage**.
5. File name: Select `Capstone_GIS_Repository.gpkg`.
6. Layer name: Enter clean semantic names (e.g., `watershed_boundary`, `contour_10m`, `georef_toposheet_extent`).
7. Save all project layer styles inside the GeoPackage: right-click layer $\rightarrow$ **Properties $\rightarrow$ Style $\rightarrow$ Save Style... $\rightarrow$ In Database (GeoPackage)**.
:::
