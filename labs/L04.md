# Lab 4: Attribute Table Operations, Field Calculator & Spatial Expressions

**Course Code:** CE452 | **Credits:** 2 | **Week:** 4  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO2, CO3 (L3, L4)  
**Primary Tools:** QGIS Field Calculator, SQL Expressions, Geometry Functions

---

## 🎯 Aim & Objectives
1. Inspect, edit, and manipulate non-spatial tabular data linked to spatial vector geometries.
2. Utilize the **Field Calculator** to dynamically compute planar geometric properties: `$area`, `$length`, and `$perimeter`.
3. Construct SQL-style **Expressions** for filtering, selecting, and classifying features based on conditional criteria.
4. Execute table joins between spatial layers and non-spatial CSV datasets (e.g. ward population census or water demand statistics).

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Calculating Geometric Properties
:::steps
1. Load your `Buildings` polygon layer from Lab 3.
2. Open the Attribute Table (`F6` or right-click layer $\rightarrow$ **Open Attribute Table**).
3. Click the **Field Calculator** icon (`Ctrl + I` - yellow abacus).
4. In the Field Calculator:
   - Check **Create a new field**.
   - Output field name: `plinth_area_sqm`
   - Output field type: `Decimal number (real)` with Precision `2`.
   - In the Expression builder box, type:
     ```sql
     $area
     ```
   - Notice the preview showing the computed area in square meters. Click **OK**.
5. Repeat for `builtup_volume_cum`:
   ```sql
   $area * "height_m"
   ```
:::

### Phase 2: Constructing Conditional Expressions
:::steps
1. In the Attribute Table, click the **Select features using an expression** button (`Select by expression` / `Ctrl + F3`).
2. Construct queries using spatial and attribute operators:
   - *Find commercial/academic buildings with plinth area > 500 sqm:*
     ```sql
     "usage" IN ('Academic', 'Commercial') AND "plinth_area_sqm" > 500
     ```
   - *Classify roof runoff harvesting potential into a new text field `harvest_category`:*
     ```sql
     CASE 
       WHEN "plinth_area_sqm" > 1000 THEN 'High Yield Priority'
       WHEN "plinth_area_sqm" BETWEEN 400 AND 1000 THEN 'Medium Yield'
       ELSE 'Low Yield'
     END
     ```
3. Observe selected features highlighted in yellow on the map canvas.
:::
