# Lab 9: Hydrological Watershed & Drainage Network Delineation

**Course Code:** CE452 | **Credits:** 2 | **Week:** 9  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO4 (L4, L5)  
**Primary Tools:** QGIS Processing, SAGA GIS Hydrology, GRASS GIS

---

## 🎯 Aim & Objectives
1. Understand the theoretical flow routing principles over raster surfaces (**D8 Flow Direction Algorithm**).
2. Perform hydrological DEM conditioning: **Sink (Depression) Filling**.
3. Compute **Flow Direction** and **Flow Accumulation** grids.
4. Extract synthetic river stream channels using contributing drainage area thresholds.
5. Delineate the exact upstream contributing **Catchment Watershed Boundary** for a designated bridge/dam outlet point.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: DEM Pre-Processing & Sink Filling
:::steps
1. Load your projected DEM (`DEM_UTM.tif`).
2. Raw DEMs contain spurious digital pits/sinks that trap virtual water.
3. Open **Processing Toolbox** $\rightarrow$ Search for **Fill Sinks (Wang & Liu)** or **r.fill.dir** (GRASS).
4. Set Minimum slope: `0.01 degrees`.
5. Output: `DEM_Filled.tif`.
:::

### Phase 2: Flow Direction & Accumulation
:::steps
1. In Processing Toolbox, search for **Flow Accumulation (Top-Down)** or **r.watershed**.
2. Run on `DEM_Filled.tif`.
3. Outputs generated:
   - **Flow Direction Raster**: Encodes the direction of steepest downward slope (D8 values: 1 to 128).
   - **Flow Accumulation Raster**: Cell values indicate the count of upstream cells draining through each pixel. High accumulation lines form river streams!
:::

### Phase 3: Stream Extraction & Catchment Polygonization
:::steps
1. In **Raster Calculator**, extract streams exceeding 1000 contributing upstream cells:
   ```sql
   "Flow_Accumulation@1" > 1000
   ```
2. Vectorize the stream raster using **r.to.vect** (Lines) $\rightarrow$ `Streams_Extracted.shp`.
3. Pick a proposed bridge crossing or reservoir dam site on the stream network.
4. Run **Upslope Area** (SAGA) or **r.water.outlet** (GRASS):
   - Input: Flow direction raster + Outlet point coordinates $(X, Y)$.
   - Output: Binary catchment raster.
5. Convert catchment raster to vector polygon (**Raster $\rightarrow$ Conversion $\rightarrow$ Polygonize**).
6. In Field Calculator, compute the total drainage catchment area: `$area / 1000000` (in $\text{km}^2$).
:::

## 📋 Deliverables
1. Delineated catchment polygon boundary (`Catchment_Boundary.shp`) with calculated catchment area in $\text{km}^2$.
2. Vector drainage stream network classified by Strahler Stream Order.
