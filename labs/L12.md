# Lab 12: Supervised & Unsupervised Satellite Image Classification

**Course Code:** CE452 | **Credits:** 2 | **Week:** 12  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO5 (L4, L5)  
**Primary Tools:** QGIS Semi-Automatic Classification Plugin (SCP) / Orfeo ToolBox

---

## 🎯 Aim & Objectives
1. Understand the theoretical difference between **Supervised Classification** (user-defined training sites) and **Unsupervised Classification** (clustering algorithms: K-Means / ISODATA).
2. Create **Training Input Regions of Interest (ROIs)** for major Land Use / Land Cover (LULC) classes: Water, Built-up, Dense Forest, Agricultural Crops, and Barren Land.
3. Train and execute a **Maximum Likelihood** and **Random Forest** supervised classifier.
4. Perform post-classification accuracy assessment: compute **Overall Accuracy (%)** and **Kappa Coefficient ($\kappa$)** from an error confusion matrix.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Training Input ROI Creation
:::steps
1. In QGIS, install and open the **Semi-Automatic Classification Plugin (SCP)**.
2. In the SCP Dock panel, set the Input Image Band Set to your Sentinel-2 stacked bands.
3. Create a new Training Input file (`training_rois.scp`).
4. Using the ROI polygon tool, collect at least 10 pure, representative training polygons for each Macro-Class (MC):
   - **MC ID 1**: Water Bodies (deep lakes, reservoirs, wide rivers)
   - **MC ID 2**: Forest / Dense Vegetation
   - **MC ID 3**: Agricultural Croplands
   - **MC ID 4**: Urban / Built-up Infrastructure
   - **MC ID 5**: Barren Soil / Fallow Land
5. Inspect the spectral signature curves in the SCP spectral window to ensure classes do not exhibit severe spectral overlap.
:::

### Phase 2: Running Supervised Classification
:::steps
1. Switch to the **Classification** tab in SCP.
2. Algorithm: Select **Maximum Likelihood** (or Random Forest).
3. Check option to use **MacroClass ID**.
4. Click **Run** and save the thematic raster as `LULC_Classified_2026.tif`.
:::

### Phase 3: Accuracy Assessment (Error Matrix)
:::steps
1. Collect 50 random ground truth verification points across high-resolution Google Satellite imagery.
2. Run **Accuracy Assessment** in SCP or Processing Toolbox.
3. Review the generated Error (Confusion) Matrix:
   $$\text{Overall Accuracy} = \frac{\sum \text{Correctly Classified Pixels on Diagonal}}{\text{Total Validation Pixels}} \times 100$$
4. Verify that Overall Accuracy exceeds **85%** and Kappa $\kappa > 0.80$.
:::
