# Lab 6: Vector Spatial Analysis: Buffer, Overlay & Geoprocessing

**Course Code:** CE452 | **Credits:** 2 | **Week:** 6  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO3 (L4 - Analyze)  
**Primary Tools:** QGIS Vector Geoprocessing, Buffer, Intersect, Dissolve, Voronoi

---

## 🎯 Aim & Objectives
1. Perform distance proximity modeling using the **Buffer** tool (e.g. river corridor environmental protection zones).
2. Execute vector topological overlays: **Intersection**, **Union**, **Difference**, and **Clip**.
3. Generate **Voronoi (Thiessen) Polygons** for spatial influence estimation of point rainfall/monitoring stations.
4. Solve a real civil engineering hazard problem: Identify land parcels located inside a 50-meter river flood hazard setback.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Proximity Buffering
:::steps
1. Load river centerline vector layer and building footprints (both projected in UTM meters).
2. Navigate to **Vector $\rightarrow$ Geoprocessing Tools $\rightarrow$ Buffer...**.
3. Set:
   - Input layer: `Rivers`
   - Distance: `50.0 meters`
   - Segments: `10` (controls smoothness of curved end caps)
   - End cap style: `Round`
   - Check $\checkmark$ **Dissolve result** (merges overlapping river buffer segments into a continuous hazard corridor).
   - Output layer: `River_Hazard_Buffer_50m.shp`.
4. Click **Run**.
:::

### Phase 2: Spatial Overlay & Hazard Intersection
:::steps
1. Navigate to **Vector $\rightarrow$ Geoprocessing Tools $\rightarrow$ Intersection...**.
2. Set:
   - Input layer: `Buildings`
   - Overlay layer: `River_Hazard_Buffer_50m`
   - Output: `Buildings_At_Flood_Risk.shp`
3. Click **Run**. Open the attribute table of the result: every building feature intersected inside the buffer zone is extracted with both building and flood hazard attributes.
:::

### Phase 3: Voronoi / Thiessen Polygons
:::steps
1. Load rain gauge station points.
2. Go to **Vector $\rightarrow$ Geometry Tools $\rightarrow$ Voronoi Polygons...**.
3. Set Buffer region: `20%`. Click **Run**.
4. Clip the Voronoi polygons with the district boundary. Each polygon represents the area of influence for that rain gauge.
:::
