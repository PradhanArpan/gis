## 🎯 Aim & Objectives
1. Understand normalized ratio spectral formulas used in environmental and water resources engineering.
2. Compute **Normalized Difference Vegetation Index (NDVI)** to evaluate canopy vigor and crop health.
3. Compute **Normalized Difference Water Index (NDWI)** to delineate surface lake/reservoir water bodies.
4. Compute **Normalized Difference Built-up Index (NDBI)** to distinguish urban concrete/asphalt from bare soil.
5. Apply thresholding to create binary surface water extent masks.

## 📐 Mathematical Formulations
1. **NDVI (Normalized Difference Vegetation Index)**:
   $$\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}} = \frac{B_8 - B_4}{B_8 + B_4}$$
   *(Values range from $-1.0$ to $+1.0$. Water: $< 0$; Bare soil: $0.1 - 0.2$; Healthy vegetation: $> 0.5$)*.

2. **NDWI (McFeeters Normalized Difference Water Index)**:
   $$\text{NDWI} = \frac{\text{Green} - \text{NIR}}{\text{Green} + \text{NIR}} = \frac{B_3 - B_8}{B_3 + B_8}$$
   *(Water features exhibit positive values $> 0$; terrestrial vegetation and soil exhibit negative values)*.

3. **NDBI (Normalized Difference Built-up Index)**:
   $$\text{NDBI} = \frac{\text{SWIR} - \text{NIR}}{\text{SWIR} + \text{NIR}} = \frac{B_{11} - B_8}{B_{11} + B_8}$$

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Raster Calculator Syntax
:::steps
1. Navigate to **Raster $\rightarrow$ Raster Calculator...**.
2. **Computing NDVI**:
   - Double-click bands to assemble formula:
     ```
     ("B08@1" - "B04@1") / ("B08@1" + "B04@1")
     ```
   - Output layer: `NDVI_Sentinel2.tif` (Output format: `GeoTIFF`).
   - Click **OK**.
3. **Computing NDWI**:
   - Formula:
     ```
     ("B03@1" - "B08@1") / ("B03@1" + "B08@1")
     ```
   - Output layer: `NDWI_Water.tif`.
:::

### Phase 2: Classification by Thresholding
:::steps
1. Right-click `NDVI_Sentinel2.tif` $\rightarrow$ **Properties** $\rightarrow$ **Symbology**.
2. Render type: **Singleband pseudocolor**.
3. Color ramp: `RdYlGn` (Red to Yellow to Dark Green).
4. Mode: `Equal Interval`, Classes: `5`.
   - $< 0.1$: Water / Barren (Brown/Red)
   - $0.1 - 0.3$: Sparse vegetation / Grassland (Yellow)
   - $0.3 - 0.6$: Moderate canopy (Light Green)
   - $> 0.6$: Dense forest / Healthy agriculture (Deep Green)
5. **Extracting Lake Surface Area**:
   - In Raster Calculator:
     ```
     "NDWI_Water@1" > 0.0
     ```
   - All cells meeting the threshold receive a value of `1` (Water), all others `0` (Land).
   - Convert binary water mask to polygon and calculate total reservoir surface area in hectares!
:::
