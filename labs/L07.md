# Lab 7: Thematic Cartography, Symbology & Print Layout Design

**Course Code:** CE452 | **Credits:** 2 | **Week:** 7  
**Estimated Time:** 120 Minutes | **Mapped Outcome:** CO2, CO3 (L3, L4)  
**Primary Tools:** QGIS Symbology, Print Layout Composer, Cartographic Rules

---

## 🎯 Aim & Objectives
1. Apply cartographic principles: color theory, visual hierarchy, symbol classification, and typography.
2. Configure **Categorized** and **Graduated (Choropleth)** symbology schemes with ColorBrewer palettes.
3. Master the **QGIS Print Layout** environment to design publication-grade, printable civil engineering map sheets (A3 / A4).
4. Add mandatory cartographic elements: **Dynamic Scale Bar**, **North Arrow**, **Graticule Grid**, **Legend**, **Title Block**, and **Metadata Citation**.

---

## 🛠️ Step-by-Step Hands-On Procedure

### Phase 1: Advanced Layer Symbology
:::steps
1. Right-click your district ward polygon layer $\rightarrow$ **Properties** $\rightarrow$ **Symbology**.
2. Change the top dropdown from *Single Symbol* to **Graduated**.
3. Value: Select `population_density_sqkm` or `runoff_coefficient`.
4. Color Ramp: Select `YlOrRd` (Yellow-Orange-Red) or `Viridis` (colorblind-safe).
5. Mode: Select **Natural Breaks (Jenks)** with `5 classes`. Click **Classify** $\rightarrow$ **Apply**.
:::

### Phase 2: Building the Print Layout
:::steps
1. Go to **Project $\rightarrow$ New Print Layout...** (`Ctrl + P`). Name it `District_Thematic_Map`.
2. Right-click the blank canvas $\rightarrow$ **Page Properties** $\rightarrow$ set Size to `A4`, Orientation to `Landscape`.
3. Click **Add Map** icon (left toolbar) and drag a large rectangle filling the upper/center area.
4. Set Map Scale to a round number (e.g. `1:25,000` or `1:50,000`).
5. In Item Properties, scroll down to **Grids**:
   - Click `+` to add Grid 1.
   - Grid Type: `Cross` or `Solid`.
   - Interval: X = `1000 m`, Y = `1000 m` (or `0.05` degrees).
   - Check $\checkmark$ **Draw Coordinates** (format: `Degree, Minute with Suffix`, margin alignment: `Inside Frame`).
:::

### Phase 3: Adding Cartographic Metadata
:::steps
1. Click **Add North Arrow** $\rightarrow$ place in the top-right corner.
2. Click **Add Scale Bar** $\rightarrow$ place in the bottom-left $\rightarrow$ set style to `Double Box`, units to `Kilometers`.
3. Click **Add Legend** $\rightarrow$ uncheck *Auto update* $\rightarrow$ remove unwanted layers $\rightarrow$ rename items with clear titles.
4. Click **Add Label** for Title Block:
   ```
   CE452 GIS LABORATORY — CHRIST UNIVERSITY
   MAP TITLE: THEMATIC STUDY OF WATERSHED INFRASTRUCTURE
   DATUM: WGS 84 | PROJECTION: UTM ZONE 45N | DATE: 2026-27
   PREPARED BY: [STUDENT NAME] (REGISTER NO: ...)
   ```
5. Export the final layout: Click **Export as PDF** (`300 DPI`).
:::
